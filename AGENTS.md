# AGENTS.md — brand-guide repo

All brand rules for every agent live in [`brand-kit/`](brand-kit/AGENTS.md). Read `brand-kit/AGENTS.md` and `brand-kit/VERSION` before any brand work.

Maintaining this repo: the Google Doc is the only rulebook. Never hand-edit generated files (`brand-kit/brand-guide.md`, `brand-kit/tokens/tokens.css`, `brand-kit/chatgpt-operator-brief.md`); change the source and run `python3 brand-kit/build.py`. A version bump = edit `brand-kit/VERSION`, then run the build. CI fails if any version header differs from `VERSION`.
