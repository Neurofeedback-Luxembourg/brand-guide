# Button

A single clear action; the primary one is usually the free, non-binding phone call.

- `nfl-btn nfl-btn--primary`: magenta fill, white label (7.80:1). One per view.
- `nfl-btn nfl-btn--secondary`: white with a plum-deep outline, for the second choice.
- `nfl-btn nfl-btn--on-gradient`: white button on the gradient hero.
- Labels are verbs in the reader's words ("Réserver un appel gratuit"), never urgency ("Dernières places !").
- Focus shows `focus-ring`. Use `<a>` for navigation, `<button>` for actions.
