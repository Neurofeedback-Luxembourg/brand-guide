# MythStrip

"Myth or number?" / « Idée reçue ou chiffre ? »: a short strip between sections that states a common belief and reveals the answer from a figure already on the page.

- Gradient ground, `on-brand` text, at most one per section.
- The reveal is a native `<details>`; the answer links to the figure card it comes from. Never introduce a number that is not on the page.
