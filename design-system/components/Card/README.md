# Card

A lilac surface that groups one idea: a service, a step, a question.

- `nfl-card` with an `h3` in plum-deep and body text in ink.
- Rounded `radius-lg`, padding `space-6`; in a grid, gap `space-6`.
- Service cards follow: goal → how it works → what is measured → who it may suit.
- Never put lilac text on white, and never a coloured left border.
