# Hero

The page or slide opener: the gradient with white text and the logo badge top-right.

- One per view; the only gradient area on the page.
- Title in plain words (goal first), one supporting sentence, optional `nfl-btn--on-gradient`.
- Logo: `logo-white.png` inside `nfl-badge` (top-right). Never a redrawn logo.
- No photos of people in distress; if an image is added it sits beside the text, never behind it.
