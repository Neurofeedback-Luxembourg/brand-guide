# ShareMenu

Plain share links on every card and chart: LinkedIn, Facebook, X, WhatsApp, email and "Copy link". No third-party share scripts.

- Links point to the section's short URL (e.g. data.neurofeedback-luxembourg.com/work/#figure-id), which carries the section's own preview image.
- A native `<details>` popover; Escape and a click outside close it. Without JavaScript "Copy link" becomes a selectable text field.
- Each click is tracked as `share_click` with the network, after cookie consent only.
