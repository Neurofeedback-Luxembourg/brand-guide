# ClaimTag

The claim-ladder label (Brand Guide §5) on every figure, study and opinion: Fact · Research finding · Our observation · Opinion.

- Uppercase `label` style on white, 1.5 px border in the tag colour, `radius-sm`.
- Each level has its own colour AND its own shape (square, circle, diamond, triangle), so the level never depends on colour alone.
- FR: Fait · Résultat de recherche · Notre observation · Opinion.
