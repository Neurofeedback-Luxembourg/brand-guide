# AboutFigure

The expandable "About this figure" / « À propos de ce chiffre » detail: caveats, population, period and the full source with page reference.

- A native `<details>`/`<summary>` with a round plus/minus marker; works with keyboard and screen readers without scripts.
- This is where the careful wording lives, complete and accurate, so the headline sentence can stay confident.
- Also used as "Show as table" inside ChartFrame.
