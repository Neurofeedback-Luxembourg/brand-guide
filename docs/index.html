Usage rules

Do

  • Use the brand gradient on hero, footer, primary CTA — it's the brand's signature gesture.
  • Pair plum-teal for UI; magenta-cyan only for the 3D brain illustration.
  • Keep :focus-visible outlines (2px #026D66 teal at 2px offset).
  • Use #9F016B magenta for campaign emphasis, max 1 element per viewport.

Don't

  • Don't use illustration magenta or cyan for body text, button fills, or focus rings.
  • Don't render Myriad Pro as live text on web — embed logos as SVG/PNG.
  • Don't introduce new brand colors without updating semantic.json first.
  • Don't use medical-claim language ("treatment", "cure", "diagnosis") — see compliance.json.
